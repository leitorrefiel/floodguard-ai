# NOAH-Inspired FloodGuard Map Update

## Reference Checked

Project NOAH: `https://noah.up.edu.ph/`

The main site requires JavaScript, but public indexed pages describe key features such as hazard maps, hazard level cards, map pins, layer controls, opacity controls, legends, weather layers, and critical facility overlays.

## FloodGuard Features Added

- Interactive OpenStreetMap hazard map.
- Tap-to-move assessment pin.
- Flood hazard overlay with low, medium, and high levels.
- 5-Year, 25-Year, and 100-Year return period selector.
- Overlay opacity slider.
- Toggle for flood hazard layer.
- Toggle for critical facility markers.
- Hazard legend.
- Local hazard summary card.
- Critical facility markers for evacuation center, school, hospital, and fire station.
- Live weather card retained from the Open-Meteo API integration.

## Important Note

The current FloodGuard hazard overlays are prototype/reference visual zones around Baliwag. They are inspired by Project NOAH's map workflow, but they are not official NOAH hazard datasets.
